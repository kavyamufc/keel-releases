• A new Security page lists apps with something Keel can prove: an update the developer marked critical, an update whose notes mention a security fix, an outdated Sparkle with published security advisories, an Electron version that no longer gets security fixes, and a signature Gatekeeper doesn't accept. Each finding says where its evidence comes from.
  • Security updates get a Security tag and come first on Updates.
  • Automatic installs can be limited to security updates (Settings, Installing).
  • Keel works all of this out on your Mac. The lists of affected versions come with Keel's signed catalog, so they stay current without a new Keel, and nothing about your apps is sent anywhere.
  • An app whose own updater installs its new version, such as Comet, no longer has a tick box on Updates, and Select all counts only apps Keel can update.
