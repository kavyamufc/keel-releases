What's New in Keel

Download Keel

Keel 1.9.2

  • Each update's source ("Homebrew ●", "App Store ●") sits right next to its buttons, in the same place in every list and filter. Room for wider buttons is kept only while an update that needs them runs.

Keel 1.9.1

  • Install and Relaunch in the side panel works, and both buttons show "Installing and relaunching…" the moment you press one. If nothing happens within 30 seconds, the buttons come back.
  • Release notes in the side panel read as formatted text: headings, lined-up bullets, bold and links.
  • Each update's source ("Homebrew ●", "App Store ●") sits in its own column before the buttons, lined up on every row.
  • If What's New can't load its notes after an update, Keel tries again later instead of skipping it.

Keel 1.9.0

  • The progress rope keeps one length while an update runs: changing percentages and buttons no longer stretch or shrink it.
  • Cursor updates come from Cursor's own update service (3.29.9 while Homebrew had 3.28.7), marked "From Keel's catalog".

Keel 1.8.4

  • Fixes update runs that stayed on "Waiting" after Keel 1.8.3: App Store and Homebrew updates start again.

Keel 1.8.3

  • Fixes App Store and Homebrew updates that finished but stayed on their last percentage: the update is done, and the row now says so.

Keel 1.8.2

  • App Store updates follow your own Apple Account's store: an update out there first (like WhatsApp 26.43.77 in India) now shows, marked "Out in your store first".
  • Without mas, choose a second store in Settings › Updates › App Store country.

Keel 1.8.1

  • App Store updates through mas show real progress ("Downloading… 45%"), then "Installing…", and share the run's one Touch ID prompt.
  • Cancel is offered only while an App Store update waits its turn; once mas starts it can't be stopped partway.
  • A selected row's status and versions stay readable (white on the blue selection).
  • After updating from a Keel version that didn't record what you'd seen, the new version's notes still show once.

Keel 1.8.0

  • See what's new in each Keel version: a What's New button beside Install and Relaunch, a one-time card after Keel updates, and Help › What's New in Keel.
  • App Store updates open the app's own App Store page, where the Update button works even before the Updates page lists it.
  • Handing an update to the App Store no longer holds up Keel: the run finishes at once, and the row offers Open in App Store and Stop Waiting.
  • With mas installed, App Store updates show what's happening and the download size while they install.

Keel 1.7.0

  • Keel's own source catalog: hand-researched update sources for apps nothing else covers, signed and checked daily. OnyX is the first.
  • Not Covered apps have Ask Keel to Cover This App, which opens a ready-filled request on GitHub.

Keel 1.6.1

  • Zoom updates are found again (two Homebrew casks claimed it).

Keel 1.6.0

  • Missed updates fixed: Firefox 159.0.1, Zoom, and App Store releases now show as soon as they're out.
  • One Touch ID prompt per Homebrew run, right when you click.
  • Each row shows one status line, like "Downloading… 99% · 208 of 210 MB"; apps waiting for Homebrew can be cancelled.
  • Finished rows stay until the run ends; apps Keel quit are reopened and say so.
  • Docker updates keep its helper tools, so it doesn't ask for your password; the Docker page lists your images and updates them.
  • New settings: Appearance, Include Keel in Update All, and Microsoft apps through Microsoft AutoUpdate.
  • Check Now and other second buttons are green; buttons stay off while their action runs.

Keel 1.5.1

  • Homebrew downloads show real MB and percentage, and the rope appears as soon as you press Update.
  • Keel's own update happens inside Keel, with no Sparkle windows, and installs itself after the other apps.
  • Quitting Keel while updates run asks first.

Keel 1.5.0

  • Touch ID for administrator passwords.
  • Search moves to a bar at the bottom of each list; the top bar is see-through.
  • Check Now and other page buttons are tinted, and the progress rope ties a knot as it goes.
  • Keel downloads as a DMG: open it and drag Keel to Applications.
