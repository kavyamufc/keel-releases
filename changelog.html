What's New in Keel

Download Keel

Keel 1.15.0

  • Updates: an "Include in Update All" button beside "Open Homebrew" lets Update All update your Homebrew packages too ("Leave out" turns it off again). It's the same setting as in Settings.
  • Apps whose new version macOS won't open, because Homebrew disabled the cask for failing Apple's check, now say so on their row and offer the Download Page instead of an Update button that would fail. They aren't counted as waiting.
  • When Keel refuses a download for its signature, it remembers that version and doesn't try it again; the row offers the Download Page until a newer version comes out.
  • GitHub releases with several Mac files: Keel now skips command-line tools, picks the build for the newest macOS your Mac runs, and prefers the file named after the app, instead of giving up.
  • Cancelling the App Store's prompt during an update now shows "Cancelled · still available" instead of a failure, with no popup.
  • App Store errors now show one clean line instead of the App Store tool's progress bars.
  • The popup after Update All lists at most five apps, so its OK button is always on screen.
  • An update that failed but is still available is counted at the top of Updates, instead of "Everything is up to date".

Keel 1.14.2

  • Apps whose Homebrew download comes from the developer's GitHub releases are now also checked against those releases, so a new version shows on Updates even before Homebrew lists it (Vorssaint 3.4.5, for example).
  • While Keel checks, "updates found so far" counts only updates that will appear on Updates; versions Keel is holding back, and apps you ignored, snoozed or skipped, no longer count.

Keel 1.14.1

  • An app whose installer renames it is no longer reported as failed: after an update, Keel finds the app again by its identifier, counts the update when the new version is there, and says so ("Updated to 158.0.4370.33 · now Copilot.app"). Keel's list, reopening and later updates use the new name. This happened with Microsoft 365 Copilot, which Microsoft renamed to Copilot.

Keel 1.14.0

  • Homebrew updates show on Updates as soon as Homebrew knows them: when Homebrew already has a newer version of an app it installed, Updates offers it straight away, and every check now asks for Homebrew's latest list, not only Check Now.
  • Settings › Sources › Connections lists every server Keel has reached, what for, how many apps, and the country, with an all-time count and Export as CSV. It stays on your Mac; countries come from a table inside Keel.
  • Claude: when Claude's own updater has a new version ready, its row says so with a Restart Claude button. Otherwise Keel waits two days before offering a new Claude version, while Anthropic rolls it out.
  • After you start an update, an app Keel quit comes back in front with its window, and the row says "reopened" only once it really did (otherwise "didn't come back", with Open).
  • Not Covered apps get Request Coverage, ready for Keel's own request service; until it's switched on, the button opens GitHub as before.
  • Clearer messages when this Mac can't look up a download server (check your VPN, DNS filter or firewall app), and when a server still hands out the previous version (Keel tries again at the next check).

Keel 1.13.1

  • Fixed: on Keel's own row, What's New and Install and Relaunch sat on top of each other when Keel's update was ready. They're side by side again.

Keel 1.13.0

  • Fixed: when two downloads started together, one app's progress could show in another's row, the bar jumped back and forth, and one download never finished (Cancel couldn't stop it either). Each download now keeps to its own row, and the bar only moves forward.
  • A download never sits silently: the row says "Connecting…" until data arrives, a download that gets nothing for a minute starts once more on its own, and if it stalls again the row says so and the run carries on.
  • Homebrew apps download up to three at once and then install one at a time, and Homebrew and App Store updates now run side by side.
  • Keel keeps a short log of each download in ~/Library/Logs/Keel/updates.log (7 days).

Keel 1.12.1

  • App Store updates show up sooner: every check now also asks your App Store account, so a new version appears as soon as your store has it, even while Apple's public listing still shows the old one or doesn't answer. Those rows say "Out in your store first".

Keel 1.12.0

  • While Keel checks, it shows how far it has got: "Checking 23 of 65 · 2 updates found so far", the app it just checked, and a thin bar, on Updates, All Apps and in the menu bar panel. With Reduce Motion on, the app name stays still.
  • Activity says how each update happened: Automatic, By you, or Outside Keel. A control at the top shows just one kind, and the notification after an automatic run opens the automatic ones. Updates recorded before this version say nothing rather than guess.
  • Update runs are faster: up to three apps download at once, Homebrew and App Store updates start straight away, and each app installs as soon as its own download is checked. Updates that need your password still install together at the end.
  • The Updates summary names apps whose own updater installs them: "4 updates are ready · 1 more installs itself".
  • The Security page is off the sidebar by default (Settings › General › Show Security page). Each app's details panel shows its own findings, and security updates still sort first with their red tag.

Keel 1.11.1

  • An app you installed with Homebrew, such as DBeaver, is counted once: the "Homebrew packages waiting" note on Updates, the Dock badge and the menu bar no longer count it a second time as a package. The Homebrew page still lists it.

Keel 1.11.0

  • A new Security page lists apps with something Keel can prove: an update the developer marked critical, an update whose notes mention a security fix, an outdated Sparkle with published security advisories, an Electron version that no longer gets security fixes, and a signature Gatekeeper doesn't accept. Each finding says where its evidence comes from.
  • Security updates get a Security tag and come first on Updates.
  • Automatic installs can be limited to security updates (Settings, Installing).
  • Keel works all of this out on your Mac. The lists of affected versions come with Keel's signed catalog, so they stay current without a new Keel, and nothing about your apps is sent anywhere.
  • An app whose own updater installs its new version, such as Comet, no longer has a tick box on Updates, and Select all counts only apps Keel can update.

Keel 1.10.0

  • Pause a running update: Pause sits beside Cancel All, stops the downloads straight away and holds the rest; Resume carries each download on from where it stopped. An install or Homebrew upgrade already under way finishes first, and once nothing is installing you can quit without being asked to wait.
  • Each app counts as done the moment its own install finishes: the Updates number, the Dock badge and the menu bar go down one by one during a run, not all at the end.
  • Clicks in the details panel land where you click. Update, the section headers and the release-notes links no longer fold the section below by mistake.
  • The details panel asks about an open app itself (Quit and Update, or Skip), and its top no longer jumps when the button turns into progress.
  • Keel refreshes Homebrew's catalog itself, at most once an hour, so its Homebrew count is current. The Homebrew page shows how old the catalog is.
  • Apps you installed with Homebrew update through Homebrew whenever Homebrew has the new version, so Homebrew's record stays right. When Keel updated an app directly and Homebrew's record is behind, the Homebrew page says "Already 5.1.2 on disk" instead of counting it, with a button to update Homebrew's record.
  • Update All can also update your Homebrew packages, after the apps (Settings, Installing).
  • Update All can check for new updates first, so it installs what came out since the last check (Settings, Installing).
  • "Always force quit" for apps that won't quit to be updated, such as Ollama. Keel never force quits the app you're using. Turn it off in the app's Automation section or its right-click menu.
  • A GitHub token (Settings, Sources) raises GitHub's limit from 60 checks an hour to 5,000. It stays in your Keychain. When the limit is reached, Keel says when checks resume and keeps what it knew.
  • Comet and other apps with a Chrome-style updater: Keel asks their own update server and shows a newer version with Open, for the app to install itself.

Keel 1.9.3

  • Check Now always gets Homebrew's latest list of apps, and automatic checks refresh it every hour (was every 12), so new versions such as IntelliJ IDEA 2026.3 show the same day.
  • Updates says when Homebrew packages are waiting, with a button to open the Homebrew page.

Keel 1.9.2

  • Each update's source ("Homebrew ●", "App Store ●") sits right next to its buttons, in the same place in every list and filter. Room for wider buttons is kept only while an update that needs them runs.

Keel 1.9.1

  • Install and Relaunch in the side panel works, and both buttons show "Installing and relaunching…" the moment you press one. If nothing happens within 30 seconds, the buttons come back.
  • Release notes in the side panel read as formatted text: headings, lined-up bullets, bold and links.
  • Each update's source ("Homebrew ●", "App Store ●") sits in its own column before the buttons, lined up on every row.
  • If What's New can't load its notes after an update, Keel tries again later instead of skipping it.

Keel 1.9.0

  • The progress rope keeps one length while an update runs: changing percentages and buttons no longer stretch or shrink it.
  • Cursor updates come from Cursor's own update service (3.29.9 while Homebrew had 3.28.7), marked "From Keel's catalog".

Keel 1.8.3

Keel 1.8.2

Keel 1.8.1

  • App Store updates through mas show real progress ("Downloading… 45%"), then "Installing…", and share the run's one Touch ID prompt.
  • Cancel is offered only while an App Store update waits its turn; once mas starts it can't be stopped partway.
  • A selected row's status and versions stay readable (white on the blue selection).
  • After updating from a Keel version that didn't record what you'd seen, the new version's notes still show once.

Keel 1.8.0

  • See what's new in each Keel version: a What's New button beside Install and Relaunch, a one-time card after Keel updates, and Help › What's New in Keel.
  • App Store updates open the app's own App Store page, where the Update button works even before the Updates page lists it.
  • Handing an update to the App Store no longer holds up Keel: the run finishes at once, and the row offers Open in App Store and Stop Waiting.
  • With mas installed, App Store updates show what's happening and the download size while they install.

Keel 1.7.0
